# YT Audio Pipeline

iPhone（iOSショートカット）からYouTubeのURLを送信し、PC上のローカルサーバーで音楽ファイルを自動ダウンロード・整理するためのAPIシステムです。
ダウンロードされた音楽はメタデータとジャケット画像が埋め込まれ、かつ音量がSpotifyなどの基準（-14 LUFS）に自動調整されるため、JellyfinやFeishin、Finampなどのツールで快適な音楽ライブラリを即座に構築できます。

## 主な機能

* **ダウンロード**: yt-dlpを使用し、最高音質の音声抽出、メタデータ（曲名・アーティスト）の付与、サムネイルの埋め込みを自動で行います。
* **音量の自動均一化（ノーマライズ）**: ffmpegを用いて曲ごとの実音量（LUFS）を解析し、Spotifyなどのストリーミング基準（-14.0 LUFS）に揃えるためのReplayGainタグを自動で埋め込みます。曲が切り替わるたびにボリュームをいじるストレスから解放されます。
* **自動フォルダ整理**: ダウンロードした曲は「downloads/アーティスト名/曲名 [ID].m4a」という形式で自動的に分類保存されます。
* **Webダッシュボード機能**: ブラウザからアクセスできる専用の管理UIを搭載。ダウンロード状況のリアルタイム監視、曲の絞り込み検索、ブラウザ上での直接試聴、端末への直接ダウンロード、不要な曲の削除などが直感的に行えます。
* **サイレント常駐**: WindowsのVBScriptを利用し、PC起動時にターミナル画面を出さずにバックグラウンドで自動起動します。
* **自己修復**: VBScriptの起動時にyt-dlpを自動で最新版にアップデートし、YouTubeの仕様変更によるダウンロードエラーを未然に防ぎます。

## セットアップ手順

### 1. 必要な環境とライブラリのインストール
Python 3.10以上 および **Node.js** をインストールしてください。
（※Node.jsはYouTubeのボット対策(JSチャレンジ)を自動突破するために必須となります）

その後、プロジェクトのルートで以下のコマンドを実行して依存ライブラリを導入してください。

```bash
pip install -r requirements.txt
```

### 2. YouTubeのCookie連携 (必須: Firefox)
最近のYouTubeの仕様変更により、ダウンロードにはログイン情報（Cookie）の連携が必須となりました。
Chrome等のブラウザは強力な暗号化がかかっており外部ツールから読み取れないため、連携には **Firefox** が必要です。

1. [Firefox](https://www.mozilla.org/ja/firefox/new/) をインストールします。
2. Firefoxを起動し、[YouTube](https://www.youtube.com/) にアクセスしてご自身のアカウントでログインします。
3. ログインが完了したら、Firefoxを閉じます。

※ツールはバックグラウンドでFirefoxのCookieを自動参照するため、普段のブラウジングはBraveやChromeなどお好きなブラウザを使用して問題ありません。

### 3. 自動起動の設定
プロジェクトフォルダ内の「start_yt-audio-pipeline.vbs」のショートカットを作成し、Windowsのスタートアップフォルダ（shell:startup）に配置してください。

### 4. iOSショートカットの作成
iPhone側でYouTubeのURLをサーバーに送信するためのショートカットを設定します。
最も簡単な方法は、以下のリンクからテンプレートをダウンロードすることです。

[ショートカットを追加する (iCloud Link)](https://www.icloud.com/shortcuts/d2651ca7c99741feb71932b95f830def)

自身で手動作成する場合は、assets/shortcut_01.png を参考にアクションを組み立ててください。

### 5. PCブラウザからの追加（ブックマークレット）
PCのブラウザからワンクリックで現在開いているYouTube動画のURLをサーバーへ送信できます。

1. `assets/bookmarklet.js` を開き、コード内の `xxx.xx.xx.xx` をお使いのPC（Tailscaleなど）のIPv4アドレスに書き換えます。
2. ブラウザ（Chrome/Edge/Braveなど）のブックマークバーで右クリックし、「ページを追加」を選択します。
3. 名前を「Pipelineに追加」などに設定します。
4. URL欄に、1で書き換えた `bookmarklet.js` のコード全体を貼り付けて保存します。

## Webダッシュボード（管理画面）について
本システムには、ブラウザから直感的に操作できる管理用ダッシュボード（React/Vite製）が付属しています。
サーバーを起動後、ブラウザからアクセスすることで以下の操作が可能です。

* **リアルタイムステータス監視**: iOSショートカット等からダウンロードを開始すると、SSE（Server-Sent Events）を用いて画面上部に進捗ログがリアルタイムで表示されます。
* **ライブラリの閲覧と検索**: これまでにダウンロードした曲の一覧がサムネイル画像付きで表示されます。画面上部の検索バーから曲名やアーティスト名で絞り込みが可能です。
* **試聴とダウンロード**: 曲をタップ（クリック）すると詳細ダイアログが開き、ブラウザ上でそのまま音楽を再生したり、PC/スマホへファイルを直接保存することができます。
* **不要な曲の削除**: リスト右側のゴミ箱アイコン、または詳細ダイアログから曲を論理削除（ゴミ箱フォルダへ移動）できます。

## 外出先からの利用について（Tailscaleの推奨）
自宅のWi-Fi環境外（モバイル通信など）からiOSショートカットを実行するためには、iPhoneとPCを安全な仮想ネットワークで接続する必要があります。
本プロジェクトでは、設定が非常に簡単でセキュアなVPN構築ツールである Tailscale の導入を強く推奨します。

### 1. インストール
PCとiPhoneの両方にTailscaleをインストールし、同じアカウントでログインします。

### 2. IPの変更
iOSショートカットの送信先IPアドレスを、ローカルIPではなくTailscaleが付与するIPアドレス（100.x.x.x等）に設定してください。
これにより、場所を問わずいつでもYouTubeから楽曲を追加できるようになります。

## Jellyfin・クライアント側の推奨設定
ライブラリの整合性を保つため、以下の設定を推奨します。

* **Nfoファイルの保存**: オフ
* **アートワークのフォルダ保存**: オフ
* **インターネットからのメタデータ取得**: オフ（※yt-dlpがファイル内に埋め込んだデータを優先させるためです）
* **イメージ取得（オーディオ）**: Image Extractorのみオン

## ディレクトリ構成

```text
project_root/
├── main.py                # サーバー本体
├── start_yt-audio-pipeline.vbs       # バックグラウンド起動および自動更新用スクリプト
├── bin/                   # ffmpeg等のバイナリを格納
├── downloads/             # ダウンロードされた曲の保存先
└── assets/                # ショートカットのスクショ等の資料を格納
```
